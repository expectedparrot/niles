Niles

A local-first CRM CLI for adding contacts one by one, capturing notes, assigning tasks, and handing richer judgment work to EDSL jobs.

Start Tutorial GitHub

Initialize A CRM

Niles stores the event log, SQLite projection, and survey artifacts in `.niles/` inside the current project directory.

mkdir acme-crm
cd acme-crm
niles init
Result 
{
  "schema": "niles.envelope.v1",
  "status": "ok",
  "command": "init",
  "data": {
    "state_dir": ".niles",
    "created": [".niles/config.toml", ".niles/events/", ".niles/index/niles.sqlite", ".niles/surveys/"]
  },
  "next_steps": [
    {"label": "Add a contact", "command": "niles contact add \"Jane Doe\" --email jane@example.com", "mutates": true}
  ]
}

Add The Relationship Graph

Use direct commands instead of spreadsheet imports. A contact can be a company, person, partner, funder, vendor, or any relationship object worth tracking.

Company

niles contact add "Acme Data" \
  --tag prospect \
  --trait source=warm_intro \
  --trait priority=1 \
  --cadence-days 14

Person

niles contact add "Maya Chen" \
  --company "Acme Data" \
  --role "VP Data" \
  --email maya@acmedata.example \
  --tag buyer

Capture Notes And Tasks

Every note and task points back to a contact. Open tasks become the practical operating layer for reminders, owner queues, and lightweight reporting.

niles note add acme-data "Robin introduced us. Maya wants a short technical proof before budget review." --kind call

niles task add acme-data "Send proof outline and two relevant customer examples" \
  --due 2026-09-05 \
  --assign john \
  --tag next-step
Result

}

Ask Humans For Updates

Status requests create EDSL humanize jobs. The learned updates are imported as notes and can create follow-up tasks when the response implies action.

niles status-request export acme-data \
  --to robin \
  --question "What changed since the last Acme Data note?" \
  --out .niles/surveys/acme-status.ep

ep run .niles/surveys/acme-status.ep

niles status-request import .niles/surveys/acme-status-results.json \
  --learned-as note \
  --create-tasks

Export Recommendation Jobs

Recommendations are exported as `.ep` jobs, run by `ep`, then imported back into Niles. The CRM records the accepted next steps instead of pretending local heuristics made the judgment.

niles recommend export \
  --scope companies \
  --focus "best next step this week" \
  --out .niles/surveys/company-next-steps.ep

ep run .niles/surveys/company-next-steps.ep

niles recommend import .niles/surveys/company-next-steps-results.json

niles recommend accept rec_acme_001 \
  --assign john \
  --due 2026-09-06

Track The Team

Company context and teammates make the CRM useful for who is doing what, without requiring a full sales platform.

niles org context set "We sell EDSL-backed research workflows to teams that need repeatable AI evaluation."

niles teammate add john --name "John Horton" --role "Founder"
niles teammate add robin --name "Robin Horton" --role "Founder"

niles task list --assignee john --status open
niles report pipeline --by assignee --since 2026-09-01
